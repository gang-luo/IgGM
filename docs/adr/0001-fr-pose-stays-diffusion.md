# FR 位姿保持扩散，不退化为直接 docking 回归

FR 旋转的去噪目标可以解析分解为 `target = R_ag_body · K`，其中 `R_ag_body` 是抗原规范帧在体坐标系下的表示（由输入完全决定），`K = R_ag_glob^T · rota_orig` 是每个复合体的常量、与噪声无关，物理含义正是该抗体在该抗原上的对接朝向。因此存在一条捷径：让旋转头直接回归 `K`，delta 由 `R_ag_body @ K_pred` 解析合成 —— 噪声处理全部解析化，网络只做一次 docking 回归，指标很可能立刻变好。

**我们不这么做。** `K` 与时间步 t 无关，直接回归它会使 FR 旋转这一路不再是扩散过程：`rota_rms`、`c_out`、噪声嵌入全部失去作用，退化成单步 docking 回归器。本课题对现有方法的核心批判是"挖空 CDR 预设了对接方式"，而 FR 位姿被加噪至近乎 Haar 均匀再去噪，正是"不预设 docking"这一主张的机制支撑；换成直接回归，批判就失去了依据。

采取的折中：把 `R_ag_body`（矩阵 9 维 + rotvec 3 维）作为**输入特征**喂进旋转头，保留完整的差值 θ 参数化。网络不必再从池化几何里非线性地反解 `x_t`，但低噪声区仍由 `rota_rms` 提供尺度先验、高噪声区由 `R_ag_body` 提供几何锚点。

**逃生口**：若未来只追求指标，直接预测 `K` 是可行路径，但届时方法叙事必须相应改写 —— 不能同时声称"分层去噪不预设 docking"又让 FR 走单步回归。
